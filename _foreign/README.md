# Foreign files — not part of BigGlade

Everything in this directory belongs to an unrelated Unity project (`RNMechs`)
and was sitting loose in the BigGlade repository root.

It is inert here: BigGlade is a Godot 4.5 **GDScript** project with no
`.csproj`, no `.sln`, and no `[dotnet]` section in `project.godot`, so none of
the C# below can compile or run in this project.

A `.gdignore` file in this directory stops the Godot editor from scanning it.

## Contents

- `unity-rnmechs/snippets/` — 24 `.cs` REPL fragments referencing
  `RNMechs.Simulation.*` and `UnityEngine.*`, sent to a running Unity editor
  one at a time. Three of them write CSV logs to `C:/Projects/RNMechs/playtest/`.
  The 23 `.cs.uid` sidecars were generated by Godot when it scanned them; they
  are meaningless and can go with the `.cs` files.
- `unity-rnmechs/mcp_client/` — a Python MCP-over-HTTP client that POSTs those
  snippets to a Unity MCP server on `http://localhost:8088/mcp`.
  - `px.py` — sends C# to the `execute_code` tool
  - `mcp_call.py` — generic tool caller
  - `probe_tools.py` — lists MCP tools; hardcodes `sys.path.insert(0, "C:/Projects/BigGlade")`
    and does `from px import post`, so it only works if it sits beside `px.py`

## Recommended action

Move `unity-rnmechs/` into the actual RNMechs repository, then delete this
directory. Nothing in BigGlade references any of it.
